# Uso Previsto (Intended Purpose)

**Audiometric Report V2.1** es una herramienta ofimática y de software administrativo diseñada exclusivamente para asistir a los profesionales de la salud auditiva en la estructuración, organización, almacenamiento volátil y presentación visual de datos audiométricos introducidos de forma manual.

La aplicación realiza un mapeo visual directo (1:1) de los valores en bruto ingresados por el usuario para trasladarlos a un formato de cuadrícula estándar y automatizar la maquetación de un documento en formato PDF. El software ejecuta fórmulas aritméticas estandarizadas y de dominio público para el cálculo de promedios (ej. PTA), actuando como una calculadora básica.

**Limitaciones de Uso (Exención Diagnóstica):**

Audiometric Report no procesa información clínica para generar, inferir o influir de forma automatizada en decisiones diagnósticas, pronósticas o terapéuticas. El sistema no realiza interpolación algorítmica de datos predictivos. La interpretación clínica de los datos recopilados, los gráficos renderizados y los resultados aritméticos recae de forma exclusiva, íntegra y absoluta en el juicio del profesional sanitario que utiliza la herramienta.
