# AudiometricReport

Clinical PTA (Pure Tone Average) calculator and AMA/AAO hearing loss percentage tool with PDF report generation. Operates 100% in the browser (client-side) with no patient data sent to any server.

**Live Demo:** [https://audiometric.report](https://audiometric.report)

## Features

* Calculation of PTA (Pure Tone Average) according to clinical standards
* Calculation of AMA/AAO hearing loss percentage
* Generation of PDF reports ready to print or deliver to the patient
* Audiogram and impedance charts 
* Multi-language support: Spanish, English, German, French, Italian, Portuguese
* 100% client-side architecture: patient data never leaves the user's browser (privacy by design)

## Getting Started / Local Development

To run the project locally:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

*(Note: This application runs entirely in the browser and does not require any environment variables or API keys to function.)*

## Privacy & Compliance

This tool is designed for professional use by ENTs and audiologists. It features a strict zero-cloud data policy—no clinical or patient data is stored on external servers. 

For regulatory information, please refer to:
* [Declaración UE de Conformidad MDR](regulatory/DECLARACION_UE_CONFORMIDAD_MDR.md)
